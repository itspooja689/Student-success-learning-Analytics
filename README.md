# Student Success Learning Analytics

## Project Overview
This project analyzes student performance, attendance, engagement, wellbeing, and dropout risk using Microsoft Power BI. The dashboard helps educational institutions identify at-risk students and make data-driven decisions.

## Problem Statement
Educational institutions generate large amounts of student data. Without proper analysis, it is difficult to identify students with poor attendance, low academic performance, high stress levels, or a high risk of dropping out.

## Objectives
- Analyze student performance
- Monitor attendance and engagement
- Identify dropout risk
- Evaluate student wellbeing
- Generate actionable insights

## Tools Used
- Microsoft Power BI
- Microsoft Excel
- Power Query
- DAX

## Dataset
- 100,000 student records
- Academic, attendance, engagement, and wellbeing data

## Project Files
- Student_Success_Learning_Analytics.pbix
- student_dropout_risk_2026.csv.xlsx
- Presentation (PPT)
- Dashboard Screenshots

## Dashboard Features
- Executive Overview
- Academic Performance Analysis
- Attendance Analysis
- Dropout Risk Analysis
- Student Wellbeing Analysis

## Key Insights
- Dropout Rate: 32%
- Average Attendance: 75.10%
- Average GPA: 1.98
- Higher stress levels are associated with lower student satisfaction.
